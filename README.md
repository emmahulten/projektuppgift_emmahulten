# Frankie´s 🍒
Projektuppgift i kursen "Introduktion till webbutveckling med HTML, CSS och JavaScript", höstterminen 2026. 

## 🌱 Beskrivning
Frankie's är en responsiv webbplats skapad för en fiktiv cocktailbar i Sundsvall. Webbplatsen presenterar verksamhetens utbud, grafiska profil och kontaktmöjligheter.

Webbplatsen är utvecklad med mobile-first som utgångspunkt och anpassas till olika skärmstorlekar.

## 🛠 Tekniker
- HTML – struktur och innehåll
- CSS – design och responsiv layout med Flexbox, Grid och media queries
- JavaScript – interaktivitet och dynamisk funktionalitet
- Git och GitHub – versionshantering och publicering

✨ Funktioner
- Responsiv navigering med hamburgermeny på mindre skärmar.
- Bildkaruseller för presentation av produkter och signaturdrinkar.
- Kontaktformulär med dynamiska fält och JavaScript-validering.
- Gemensam grafisk profil och layout på webbplatsens olika sidor.
